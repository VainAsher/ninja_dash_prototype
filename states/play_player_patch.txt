
Player modularisation patch for states/play.py
=============================================

GOAL:
  Move per-frame player input + magnet logic into PlayerController,
  so PlayState delegates to a single call.

1) FIND THE EXISTING PLAYER UPDATE BLOCK

   Look in PlayState.update for code like this:

       keys = pygame.key.get_pressed()
       player.update(
           keys,
           self.game.tiles,
           dt,
           self.game.phaseable_walls,
           self.game.abilities,
       )
       player.apply_magnet_to_coins(
           [c.rect for c in self.game.coins],
           dt,
       )

   (Your exact formatting might differ slightly, but it will be:
    - get keys
    - call player.update(...)
    - call player.apply_magnet_to_coins(...))


2) REPLACE THAT BLOCK WITH A SINGLE CONTROLLER CALL

   Replace the whole block with:

       if self.game.player_controller is not None:
           self.game.player_controller.update(dt, self.game)
       else:
           # Fallback: keep the old behaviour if controller wasn't set for some reason
           keys = pygame.key.get_pressed()
           player.update(
               keys,
               self.game.tiles,
               dt,
               self.game.phaseable_walls,
               self.game.abilities,
           )
           player.apply_magnet_to_coins(
               [c.rect for c in self.game.coins],
               dt,
           )

   The rest of PlayState.update (coins, health, lives, powerups, hazards, exit)
   stays exactly as it is.
